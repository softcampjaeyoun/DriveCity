# 타일 스트리밍 (구현됨)

넓은 지역(7개 구, 약 300km²)을 한 번에 로드하지 않고 플레이어 주변만 유지해요.

## 데이터

- `npm run map:fetch -- S W N E` 가 2.2km 타일로 나눠 받고(`data/tiles/<bbox>/`), 합쳐서 원본 JSON 을 만들어요. 중단해도 받은 타일은 남아 이어받아요.
- `npm run map:build -- <원본> public/map/seoul` 이 전체를 한 번 처리(도로 그래프·건물 보강·침범 제거)한 뒤 **1km 타일**로 나눠 써요.
  - `index.json`: 원점·bbox·타일 목록(도로 길이)·시작 지점·지명·overview 정보
  - `t/{i}_{j}.json`: 그 타일의 노드(전역 번호)·간선·건물·물·공원·철도·신호등
  - `overview.png`: 큰 지도 배경 (Node 안에서 직접 래스터·PNG 인코딩)

## 런타임

- `world/tiles.ts`: 플레이어 타일 기준 3×3 을 유지. 데이터는 미리 받아 두고(바깥 링까지) 활성화는 프레임당 하나. 반경 +1 밖으로 나가면 하나씩 해제.
- `world/graph.ts`: 노드·간선이 전역 번호라 타일이 바뀌어도 참조가 유지돼요. 경로 탐색은 로드된 영역 안에서만.
- 타일이 들어오면 순서대로: 그래프 → 신호등 → 도시 메시 → 충돌 → 미니맵 → 교통 → 보행자. 나갈 땐 역순.
- 교통은 타일 도로 길이 × 1.5대/km. 타일이 내려가면 그 타일 차는 사라지고, 라이벌·경찰은 플레이어 근처 길로 옮겨요.
- 체크포인트·미션 거점·배틀 결승은 플레이어 300~900m 안의 로드된 교차로에서 골라요.

## 한계

- 타일 경계에서 아직 안 들어온 쪽 길은 막다른 길처럼 보여 AI 가 유턴해요. 플레이어 1km 앞까지는 미리 들어오므로 눈에 잘 띄지 않아요.
- 고가·지하차도는 평면이에요.
